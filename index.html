EE-Motion: An EEG-based Web Architecture for Live Affective Music Recommendation

Sabino Roccotelli1 , Potito Aghilar1 , Vito Walter Anelli1 , Alejandro Bellogín2 ,
Tommaso Colafiglio1 , Michelantonio Trizio3 , Tommaso Di Noia1
1Politecnico di Bari, Italy; 2Universidad Autónoma de Madrid, Spain; 3Wideverse, Italy
Paper Live Demo Video

EE-Motion maps in-browser EEG from a consumer headband to valence–arousal proxy coordinates and uses them to steer music recommendations for anonymous visitors without model retraining.

Abstract

Music listening is intrinsically tied to emotion, which drifts continuously within a single session. Although modern browsers interface with wearable brain-computer interfaces, recommendation systems remain structured around discrete logs and lack the infrastructure to integrate continuous physiological signals. Furthermore, existing affect-aware models rely on static user profiles and offline training, failing to serve anonymous newcomers without model retraining.

We present a web platform that resolves both challenges. Pairing with a consumer electro­encephalogram (EEG) headband over Web Bluetooth, the system captures live EEG, mapping frontal alpha asymmetry and arousal index to normalized valence-arousal proxy coordinates on Russell's circumplex plane.

Driven by these coordinates, an affective adapter unifies structurally diverse recommendation backbones under a shared live scoring mechanism. By parameterizing anonymous visitors through a few favorite tracks, the module recommends tracks conditioned on live proxy coordinates. This demonstrates that real-time EEG-derived control signals can steer recommendations without persistent user tables or model retraining.
